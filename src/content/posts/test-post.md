这是本站的第一篇测试文章 ✨ 主要用来验证以下几件事是否正常：

- 文章的封面图、标题、日期、标签、分类能否正确显示
- Markdown 排版（标题、列表、引用、代码块、表格、链接）渲染是否正常
- 文章底部的评论区（Giscus）能否加载出来
- 首页 / 归档 / 分类 / 标签页能否正确收录这篇文章

看完这篇之后，你可以直接在 `src/content/posts/` 里新建自己的文章，或者把这篇删掉。

## 为什么用这篇文章做测试

因为之前站点的文章是空的，很多页面（归档、分类、标签、RSS、搜索）都没法验证。
现在有了一篇真实文章，这些页面就都能跑通了。

有序列表：

代码块：

```js
const beat = {
  bpm: 140,
  key: "F# minor",
  genre: "Trap",
};

console.log(`正在制作一首 ${beat.genre}，${beat.bpm} BPM`);
```

表格：

| 风格 | 速度（BPM） | 特点 |
| --- | --- | --- |
| Trap | 130 - 150 | 808 低音 + 密集 hi-hat |
| Drill | 138 - 145 | 滑音 808、切分律动 |
| Boom Bap | 85 - 95 | 复古鼓组、采样感强 |
| Lo-Fi | 70 - 90 | 松弛、颗粒感、氛围 |
